# Fotos e vídeos

Coloque os arquivos com exatamente estes nomes. O site mostra cada um automaticamente; enquanto o arquivo não existir, aparece um espaço reservado.

## `fotos/`
| Arquivo | Onde aparece |
|---|---|
| `hero.jpg` | Foto principal no topo (vertical, ~4:5) |
| `depoimento-1-capa.jpg` | Capa do vídeo de depoimento (vertical 9:16) |
| `problema-1.jpg`, `problema-2.jpg`, `problema-3.jpg` | Colagem da seção "O problema não é a sua força de vontade" (a 2 é a vertical) |
| `resultado-1.jpg` … `resultado-6.jpg` | Carrossel de antes e depois |
| `sobre.jpg` | Foto do Dr. Ramon na seção "Quem é" |

## `videos/`
| Arquivo | Onde aparece |
|---|---|
| `depoimento-1.mp4` | Vídeo de depoimento (vertical 9:16) |
